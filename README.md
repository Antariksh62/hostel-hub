# Hostel Hub

**A complete UI redesign of my Hostel Management System.**

The initial version of Hostel Hub was built as an MVP, where my primary focus was on implementing the core functionality rather than spending time on the UI. Once the essential features were in place, I decided it was time for a complete redesign.

The goal? Build something that doesn't just work well, but actually feels good to use. I wanted a clean, minimal, and modern interface that makes hostel management feel less like filling out boring forms and more like using an app you'd genuinely want on your phone.

Because let's be honest even hostel management deserves a UI upgrade and if Gen Z is going to use it, it might as well look good. LOL
